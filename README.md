# TTGO LoRa32 V2.1 SX1278 433MHz

Bought this to monitor my freezer temperature. Needed something with good RF penetration (freezers are good faraday cages).

Purchased this item specifically:
- https://www.aliexpress.com/item/32872078587.html - Option: SX1278 433MHz

Works with cheap "home meteo station" type remote RF 433MHz thermometers.

## Flash

run `./flash.sh`
